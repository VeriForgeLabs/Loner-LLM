## Adding a setting later

A setting addendum may define lore, capabilities, prohibitions, genre conventions, and tone. It should not restate the generic Loner mechanics unless it deliberately overrides them.

When a setting addendum is added during an existing game:

1. Preserve already established campaign facts unless the user explicitly retcons them.
2. Apply the addendum prospectively.
3. Record any approved correction in the state ledger.
